Features

Type safety

TypeScript, native ES modules, and validated environment variables.

Validation

Zod schemas define request validation and the API contract in one place.

Database

MongoDB with Mongoose, plus database-backed session storage.

API documentation

OpenAPI generated from your schemas, with Swagger UI at /docs in development.
